# Support

For help with a project maintained by [samwise1776](https://github.com/samwise1776), use the
**Issues** section of that project's repository.

Please include enough information to understand the problem, such as:

- Project/version
- Operating system
- What you were trying to do
- What happened
- Relevant error output

Do not post passwords, authentication tokens, private keys, private
addresses, or other sensitive information.

Public projects can be found at:

https://github.com/samwise1776?tab=repositories
