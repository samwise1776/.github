# Contributing

Thanks for your interest in projects maintained by
[samwise1776](https://github.com/samwise1776).

## Before contributing

1. Read the project's README and existing documentation.
2. Check existing issues before opening a duplicate.
3. For large changes, open an issue first to discuss the idea.
4. Keep pull requests focused on one change when possible.
5. Test your changes before submitting them.
6. Never include passwords, API keys, tokens, private information,
   or other secrets in issues, commits, or pull requests.

## Bug reports

Include:

- What you expected to happen
- What actually happened
- Steps that reproduce the problem
- Operating system and relevant software versions
- Error messages with secrets/private information removed

## Pull requests

Explain what changed and why. Link related issues when available.

Thank you for helping improve the project.
