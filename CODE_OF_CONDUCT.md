# Code of Conduct

Projects using these community guidelines should remain welcoming and
focused on constructive software development.

## Expected behavior

- Be respectful.
- Discuss ideas and code rather than attacking people.
- Give useful, constructive feedback.
- Respect privacy.
- Keep discussions relevant to the project.
- Do not post harassment, hate speech, threats, or another person's
  private information.

Maintainers may remove disruptive content or restrict participation when
necessary to keep project spaces useful and safe.
