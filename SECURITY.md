# Security Policy

## Reporting a security problem

Please avoid posting passwords, tokens, private keys, personal
information, or other sensitive data in a public issue.

If GitHub's private vulnerability reporting feature is available for the
repository, use it for security-sensitive reports.

If private reporting is unavailable, open a short public issue stating
that you have a security concern without including sensitive technical
details or secrets.

## Supported versions

Security fixes generally target the latest actively maintained version of
a project unless its repository states otherwise.
